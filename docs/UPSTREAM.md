## Excluded on purpose

- **YUNG's Cave Biomes**: the repository's LICENSE reads "All Rights Reserved". Without permission we do not publish changes to it.
- **YUNG's Better Portals**: only exists for Forge 1.16.

## What this repository does and does not contain

- Contains: patch files describing our changes, build scripts, documentation. The patches are distributed under LGPL-3.0, matching the code they modify.
- Does not contain: upstream source files, compiled jars, or any author's assets.

## Official versions

Upstream now publishes a `26.1.2` branch for the newest Minecraft version. If you are on that version, use the official builds rather than anything from this repository.
